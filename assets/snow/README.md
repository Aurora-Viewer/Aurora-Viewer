# Snow textures

The detail of the snow lying on the ground (Aurora Weather).

| File | Source | Licence |
|---|---|---|
| `snow-normal-height.png` | "Snow 004" from ambientCG, https://ambientcg.com/view?id=Snow004 | CC0 1.0 |
| `snow-color-roughness.png` | the same | CC0 1.0 |

Changes: the 1K normal map (OpenGL convention, green up) and the
displacement map, downscaled to 512 × 512 (Lanczos) and packed into one
RGBA PNG: RGB the normal, A the height.

`snow-color-roughness.png`: the 2K colour map and roughness map,
downscaled to 512 × 512 (Lanczos) and packed into one RGBA PNG: RGB the
colour, A the roughness.

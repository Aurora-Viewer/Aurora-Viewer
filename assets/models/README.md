# Aurora 3D

`aurora-3d.glb` est le modèle détaillé fourni par l’utilisateur pour la
prévisualisation des matériaux : 2 342 triangles, géométrie extrudée et UV
d’origine conservées. Il est autonome, avec texture PNG embarquée.

La scène, les nœuds et les maillages portent le nom **Aurora 3D** ; le matériau,
les textures, images, buffers, vues de buffers, accessors et samplers utilisent
le même préfixe. Aucun ancien nom du modèle ne subsiste dans ces métadonnées.

L’aperçu applique le matériau examiné à toutes les faces. Le matériau et la
texture colorée intégrés au GLB restent disponibles lors d’un import du modèle.
